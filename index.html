Wreckfest Race Log is exactly what the name says — it's an online race log and note tracking tool for Wreckfest. Track every race automatically with the Telemetry plugin, or manually log them yourself here — then use the site to watch your stats improve, take notes track by track, and work toward mastering the game.

I built this site because I wanted a pretty and simple way to log my races and take notes, and I hope it helps you as much as it's helped me. — Ampp33

How to get started.

1. Create an account.

Email or Google — either works, takes about ten seconds, no credit card, no personal info (we don't need it anyway).

Create your account →

2. Install the Telemetry plugin.

Install it once. It runs quietly alongside Wreckfest and reads your results straight out of the game's own memory the instant a race ends — then posts them here automatically.

Install Telemetry →

3. Race in Wreckfest.

Any track, any variation, any car. This part happens in the game, not here.

4. Annotate.

View your latest logs on the Races screen, annotate the track diagram or add notes. Did you forget that rock at the first corner? Now's the time to make a note of that.

5. Set your goals and chase them.
